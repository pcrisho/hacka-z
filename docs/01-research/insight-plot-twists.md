# "PLOT TWIST!" (Pacífico / laChakra)

**Tu competencia lo regala**
Mañana aparece exactamente la misma solución que la tuya, pero gratis.
*¿Por qué alguien seguiría eligiéndote?*

**Sin instrucciones**
No puedes explicar cómo funciona. No hay tutorial, manual ni onboarding.
*¿Cómo harías que se entienda sola?*

**Sin letra chica**
Quieren experiencias simples y manejables. La letra chica genera fricción.
*¿Cuál es el verdadero corazón de tu solución?*

**Prohibido usar descuentos**
No puedes ofrecer promociones, cupones ni descuentos como beneficio.
*¿Qué valor real tendría tu servicio en el día a día?*

**Tu usuario gana diferente cada mes**
Un mes tiene S/2,000 disponibles y el siguiente apenas S/500.
*¿Cómo diseñarías algo que pueda seguir acompañándolo?*

**Tu cliente nunca lo usa**
Paga durante un año y nunca ocurre aquello para lo que está protegido.
*¿Cómo harías para que igual sienta que valió la pena?*
