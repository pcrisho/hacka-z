### Flujo del Usuario en 4 Pasos (Stepper Horizontal):
```
[ 1. Onboarding ]  →  [ 2. Hábitos ]  →  [ 3. Protección ]  →  [ 4. Yape / Pausa ]
  (Agente IA)          (Mente/Cuerpo)    (Derecho Ganado)       (Pay-as-you-go)
```

### Los 3 Mockups del Prototipo Real (Codeado en Next.js 16):
*(Reemplazan las pantallas genéricas antiguas por las rutas reales ya construidas)*

1. **Pantalla 1: `/hoy` — Mindful Rituals**
   * *Barra superior:* `FIBO | Hoy`
   * *Contenido:* Check-in diario con 3 rituales interactivos:
     - 🪙 Alcancía (Micro-ahorro S/ 5 - 10)
     - ⏱️ Live Timer (15-30 min actividad física)
     - 🧘 Respiración guiada 4-4-4 (30s)
   * *Estado:* `3/3 completados hoy` • Racha activa

2. **Pantalla 2: `/salida` — Salida Protegida Grupal**
   * *Barra superior:* `FIBO | Salida Protegida`
   * *Contenido:* Seguro colectivo de accidentes para salidas nocturnas o pichangas deportivas.
   * *Cotización:* **S/ 3.50 por persona** (Póliza `PAC-TRIBU-2026`)
   * *Acción:* Recaudación instantánea por Yape y pase compartido por WhatsApp.

3. **Pantalla 3: `/progreso` — Derecho Ganado & Microseguro**
   * *Barra superior:* `FIBO | Progreso`
   * *Contenido:* Gráfico de constancia en espiral + Desbloqueo de recompensa.
   * *Producto:* **Microseguro Médico Pacífico**
   * *Precio:* **S/ 9.90 / mes** (Hasta S/ 15,000 de cobertura).
   * *Control:* Switch para **pausar o reactivar sin penalidades**.

* **Estado Técnico Real:** Prototipo funcional navegable **18/18 rutas operativas**, TypeScript estricto, 0 errores de build y persistencia en cliente (PWA).
