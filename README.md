# Hacka-Z — Pacífico Seguros × Gen Z

Base de conocimiento y bitácora del equipo **Cluster Team** para la Hackathon UCSUR – Pacífico Seguros ("El futuro de los seguros para la Generación Z", Ciclo 2026-2, en alianza con AWS).

Detalle de roles en [`docs/00-bases/equipo.md`](docs/00-bases/equipo.md).

## El reto

Diseñar, en 3 entregables obligatorios, una propuesta de seguros/protección relevante para la Generación Z peruana: **Sustentación** (propuesta de valor justificada) + **MVP** (funcional o demostrable) + **Go-to-market** (segmento, canales, modelo de ingresos, métricas). Detalle completo en [`docs/00-bases/BASES-CONCURSO.md`](docs/00-bases/BASES-CONCURSO.md).

**Fechas clave:** Kick-off 01 Set. → Mentoría 04 Set. → Entrega (one-pager + video ≤3 min) 08 Set. 11:59pm → Finalistas 10 Set. → Demoday 11 Set.
